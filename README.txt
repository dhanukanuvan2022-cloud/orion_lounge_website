ORION LOUNGE & BAR WEBSITE
==========================

Files:
- index.html : Website structure and content
- style.css  : Responsive black-and-gold design
- script.js  : Menu filters, cart and WhatsApp order message
- assets/    : Images rendered from the customer-supplied 4144.pdf

HOW TO OPEN
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html to view it in a browser.
4. Internet is needed for Google Maps embed and Google Fonts.

HOW ORDERING WORKS
- Select menu categories and press + to add dishes.
- Review quantities in Your Order.
- Add name or special instructions if desired.
- Press Send order via WhatsApp.
- WhatsApp opens with the order message addressed to +94 76 416 7993.
- The customer still needs to press Send in WhatsApp.
- Items without a clearly readable price are labelled Ask for price. The message asks the restaurant to confirm prices and availability.

IMPORTANT CONTENT NOTES
- The venue address and phone number were taken from public online listings: 98 Poruthota Road, Negombo 11500, Sri Lanka; +94 76 416 7993.
- Menu item names/prices are transcribed from the supplied PDF. Some menu artwork is small/unclear, so unclear prices were not invented.
- Food/venue photos are taken from the supplied PDF and upscaled to a 4K long edge (3840 pixels). Upscaling increases dimensions but cannot recover details not present in the source.
- Review excerpts are short quotations shown on a third-party public listing and are attributed accordingly. The Google Maps button opens the current Maps search/reviews; this is not a live Google reviews API widget.
- Opening hours vary between online listings. The website asks visitors to confirm current hours by phone.
- Confirm the restaurant has approved the website, phone number, menu prices, review use and photos before publishing.

To publish, upload index.html, style.css, script.js and the assets folder together to a static host such as Cloudflare Pages or GitHub Pages.
